# Canvas 편집

Canvas는 Metadata Element를 시각적으로 배치하는 작업 공간입니다.

## 화면 이동과 확대

| 조작 | 결과 |
|---|---|
| `Space` + 드래그 | 화면 이동. **현재 도구와 선택을 유지**합니다 |
| 가운데 버튼 드래그 | 화면 이동 |
| `Ctrl/Cmd` + 휠 | **커서 기준** 확대·축소. 커서 아래 지점이 제자리에 머뭅니다 |
| Canvas Toolbar의 `-` / `+` / Frame All | 단계 확대·축소, 전체 보기 |

Hand 도구를 선택해도 이동할 수 있지만, `Space` 드래그는 도구를 바꾸지 않아 배치 작업 중 왕복이 없습니다.

## 위치·크기 입력

Canvas 바로 위 **Transform Bar**에 선택 항목의 `X` `Y` `W` `H`가 항상 표시되고 그 자리에서 편집됩니다. 라벨(`X` 등)을 좌우로 드래그하면 값이 스크럽됩니다.

여러 개를 선택하면 전체 범위를 보여 주지만 입력은 비활성화됩니다 — 네 칸으로 여러 Rect를 동시에 바꾸는 것은 의미가 모호하기 때문입니다.

## 눈금자와 안내선

Canvas 위쪽과 왼쪽에 눈금자가 있습니다. 눈금 간격은 확대 배율에 따라 1/2/5 × 10ⁿ 중 읽기 좋은 값으로 자동 조정되고, 마우스 위치가 두 눈금자에 표시됩니다.

| 조작 | 결과 |
|---|---|
| 눈금자에서 캔버스로 드래그 | 안내선 추가 |
| 눈금자 안에서 놓기 | 취소 (안내선을 만들지 않음) |
| **안내선 드래그** | **위치 이동** |
| 안내선을 눈금자 쪽으로 끌어 놓기 | 삭제 |
| `Alt` + 안내선 클릭 | 삭제 |
| 좌측 상단 모서리 상자 클릭 | 안내선 전체 삭제 |

안내선은 1px 선이지만 실제 클릭 판정은 그 주위 **11px 폭의 그립 영역**입니다. 마우스를 가져가면 선이 굵어지고 색이 바뀌어 잡을 수 있다는 것이 보입니다. Grid Snap이 켜져 있으면 안내선도 격자에 맞춰 이동합니다.

Element를 옮기면 가장자리와 중심이 다른 Element와 안내선 양쪽에 붙습니다. Element끼리는 **같은 가장자리·중심 정렬**뿐 아니라 **서로 맞대는 경우**(내 오른쪽 ↔ 상대 왼쪽)도 붙습니다.

**안내선이 다른 Element 가장자리보다 우선**합니다 — 안내선은 명시적으로 놓은 기준이고 Element 가장자리는 우연히 근처에 있는 것이기 때문입니다.

> 안내선은 확대 배율·스크롤과 같은 편집 보조 상태로 취급되어 `EditorPrefs`에 Metadata Asset 단위로 저장됩니다. Asset에 기록되지 않으므로 Git diff에 나타나지 않고 팀원과 공유되지도 않습니다.

- 클릭으로 단일 선택합니다. `Shift`는 범위/추가 선택, `Ctrl` 또는 `Command`는 선택 토글에 사용합니다.
- 빈 영역을 드래그하면 박스 선택합니다.
- 선택 Element를 드래그해 이동하고 Handle로 크기를 바꿉니다. 다중 선택 이동은 하나의 Undo 단계로 기록됩니다.
- 화살표는 1단위, `Shift+화살표`는 10단위 이동입니다.
- Context Menu에서 복제, 삭제, Group, Layer 이동과 겹친 Element 선택을 사용할 수 있습니다.
- `F`는 선택 Element가 보이도록 Canvas Scroll을 맞춥니다.
- Snap과 Smart Guide는 이동 중 정렬 기준을 보여 주지만 모든 Layout 결과를 대신하지 않습니다.
- Assets 탭이나 Project 창에서 Sprite·Font·Material·Component Definition을 Canvas로 드래그할 수 있습니다. 자세한 동작은 [Assets 패널](assets-panel.md)을 참고하세요.

재사용 Component의 Instance는 Canvas에 펼쳐진 모습으로 그려지지만, **선택과 드래그는 Instance 자체만** 대상으로 합니다. Definition에서 온 자식은 화면에 보이되 개별 선택되지 않습니다 — 그 내용을 바꾸려면 Definition을 편집하거나 Instance의 Override를 사용하세요.

## 드래그로 부모 바꾸기

Element를 **다른 Container 위로 끌고 가면 그 아래로 들어갑니다.** Unity Hierarchy에서 행을 다른 행 위에 떨어뜨리는 것과 같은 조작을 캔버스에서 하는 것입니다.

* 드롭 대상 Container에 **파란 테두리**가 표시되고, 커서 옆에 `Drop into 'panel'` 같은 문구가 뜹니다.
* 빈 캔버스에 놓으면 화면 최상위(root)로 나갑니다.
* 놓은 자리의 **화면상 위치가 그대로 유지**됩니다. 부모만 바뀌고 눈에 보이는 위치는 움직이지 않습니다.
* `Ctrl/Cmd`를 누른 채 드래그하면 **부모 변경 없이 이동만** 합니다. Container 위를 지나가야 하지만 구조는 그대로 두고 싶을 때 사용합니다.

대상 판정 규칙:

| 규칙 | 이유 |
|---|---|
| 자식을 가질 수 있는 Component만 대상 | Label 같은 Leaf에 넣으면 Validation 오류가 됩니다 |
| 자기 자신과 자기 자손은 제외 | 자기 subtree에 넣으면 가지가 끊깁니다 |
| 숨김·잠금 Element는 제외 | 보이지도 편집하지도 못하는 곳에 들어가면 함정입니다 |
| 겹치면 **가장 안쪽** Container 우선 | Panel 안의 Card 위에 놓으면 Card로 들어갑니다 |
| 같은 깊이면 나중에 그려진 것 우선 | 위에 보이는 것이 받습니다 |

이미 그 부모에 속해 있으면 아무 일도 하지 않습니다 — 의미 없는 Undo 항목을 만들지 않기 위해서입니다.

Layers 패널에서 행을 드래그하는 기존 방식도 그대로 동작하며, 형제 순서까지 지정하려면 그쪽이 더 정확합니다.

Undo/Redo는 Unity 표준 `Ctrl/Command+Z`, `Ctrl/Command+Shift+Z`를 사용합니다. 자세한 목록은 [단축키](../reference/shortcuts.md)에 있습니다.
